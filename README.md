# Multiplayer — 최소 소스 저장소

Unity 멀티플레이 슈터의 코드 보관용 저장소입니다.

- Unity: 6000.3.20f1
- 포함: Shooter / Core / Blocks 코드와 해당 메타파일, 어셈블리 정의, Packages 목록, Unity 버전 정보
- 제외: 모델, 텍스처, 머티리얼, 프리팹, 씬, 영상, 음원, 시네마틱, 빌드 결과물, Library, Temp, Logs, 개인 설정

## 사용 범위

용량을 최소화한 소스 아카이브이며 **단독 실행·빌드 가능한 완전한 Unity 프로젝트가 아닙니다.** 기존 원본 프로젝트의 대응 경로에 병합하여 사용하세요. 씬·프리팹·리소스·프로젝트 설정은 원본 프로젝트에서 별도로 준비해야 합니다. 패키지 목록에는 원본 프로젝트의 의존성을 기록했습니다.

## 주요 구현

멀티플레이 세션, 캐릭터 선택, 네트워크 무기 처리, 솔저·겐지·디바·캐서디 스킬과 전투 효과 관련 코드를 포함합니다.

타사 코드와 의존성의 권리는 각 원저작자에게 있습니다. 이 저장소에 별도의 재배포 라이선스를 부여하지 않습니다.
